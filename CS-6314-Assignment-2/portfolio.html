Projects

Semantic Image Gallery

Leverages Vision-Language Models, specifically the CLIP architecture, to projects both raw local images and textual queries into a shared, high-dimensional mathematical vector space. Vector similarity and nearest-neighbor retrieval are then executed using FAISS to ensure rapid, in-memory lookup capabilities. Enabling the accurate processing of highly descriptive, context-aware queries and provides a robust image retrieval system that operates entirely locally without the need for rigid metadata or manual text tags powered by a Gardio front end.

  • CLIP embedding generation for multi-modal vector search
  • FAISS indexing for sub-millisecond retrieval performance
  • Interactive web interface built for quick local exploration

Remedy AI

This project was made for the 2024 Axcess Hackathon and is a large language model designed specifically for healthcare, allowing users to inquire about general health concerns, receive insights on wellness practices, and gain valuable recommendations tailored to their unique needs. I trained this model using the Llama-2-7B-bf16-sharded model as the base and fine-tuned it by using LoRA on a medical dataset of 16.4k samples. Some of the technologies used for this project were the Hugging Face Transformer Library, Python Flask, Google Colab, and Paperspace Gradient.

  • Custom trained LoRa on 16.4k examples Datatset
  • Functioning basic WebUI built with Python Flask
  • Locally running an open source with no need for token limits or API fees
